# Набор портов плагинов под pi

Берём не адаптированный исходник, ищем аналоги в pi packages, сравниваем, иначе портируем его под pi

## Структура портов

```
pi-*            # имя конечного pi-пакета
    sources/    # склонированные исходники для быстрого просмотра
    docs/       # документация по портированию
    ...             # другие папки, связанные уже с портом
```
